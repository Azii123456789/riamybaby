# NEXTFLIX

An original, responsive birthday-premiere experience for Ria. Open `index.html` directly or serve this folder with any static web server.

## Personalize it

- Edit all words and paths in `config.js`.
- Replace `assets/images/ria-01.jpg` through `ria-12.jpg` with real photos (keeping the filenames is easiest).
- Add your music as `assets/audio/birthday-music.mp3`. Audio never starts until the visitor presses the visible music control inside the surprise.
- `ria-contact-sheet.png` is the original generated source sheet and may be removed after you replace the placeholders.

If a photo is missing, cards retain a dark red gradient fallback. If music is missing, the control changes to “Add music” and the rest of the experience continues normally.
